# Semantic browser routing examples

- `Buat cerita tentang robot` → no browser.
- `Siapa CEO OpenAI sekarang?` → browser search.
- `Apa saja model terbaru di OpenRouter?` → browser search.
- `Kenapa harga BTC turun hari ini?` → dedicated price data plus browser news/context.
- `Berapa harga BTC sekarang?` → dedicated crypto API remains sufficient.
- `Apa fungsi website itu?` after a prior URL → read the most recent referenced URL.
